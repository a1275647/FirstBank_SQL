# 程式變更說明

| 日期 | 版本 | 提交人 | 對應單號 |
|---|---|---|---|
| 2026-09-16 | | | |

## 變更內容

1. 【調整】資料異常監控的「資料完整性驗證通知」內容改為一筆一行，缺漏欄位改以「中文名稱(欄位代碼)」顯示，例如「事業群代號(GROUP_NO)」。
2. 【調整】「額度超限警示」與「異常通知-各單位使用餘額超逾配賦額度」內容改為依單位分組排版：單位名稱一行、底下各國家縮排一行，最後一行「請留意」。
3. 【調整】「國家使用率警示」與「異常通知-全行的各國餘額單日變動超逾100百萬美元」內容改為一個國家一行，國家名稱前不再加「國家」二字，改為「中國大陸：餘額由 … 變動為 …」格式。
4. 【修正】系統通知寄送的預警信件內容全部擠在同一行的問題；現在信件與站內通知的分行、縮排一致。
5. 【修正】電子簽核待辦通知信件中的「表單連結」原本顯示 `@#$` 標記文字且無法點擊，改為可直接點擊的連結。

## 異動範圍

| 系統 | 異動項目 |
|---|---|
| 前端 | 無 |
| 後端 | `SchedulerTaskService`：資料完整性驗證、額度超限、異常通知-各單位、國家使用率、單日變動共 5 段通知的內容排版；`NoticeHelper`：站內通知轉寄信件時，將換行、縮排與表單連結轉為信件可呈現的格式；新增單元測試 `SchedulerTaskServiceNoticeFormatTests`、`NoticeHelperMailHtmlTests` |
| 資料庫 | 無 |

## 注意事項

- 需重新部署後端 API 後變更才生效；無 SQL、無設定檔異動。
- 本次未涉及四種調借方式的簽核流程，調借功能不受影響。
- 所有透過系統通知寄出的信件（含調借還款提醒、逾期簽核提醒等）都會經過同一個轉換，內容為單行者顯示不變。
- 已存在的舊通知內容不會回頭調整，仍以舊格式顯示。
