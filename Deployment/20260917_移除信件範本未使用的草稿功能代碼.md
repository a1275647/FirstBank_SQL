## 變更內容

1. 【調整】移除信件範本模組下未實作的「郵件草稿」功能殘留：功能代碼「查詢草稿」「草稿異動」「Email 範本設定」自系統移除，角色權限設定頁不再出現這三個項目。
2. 【調整】首頁選單「信件範本」待辦數的顯示條件改為只看「信件範本異動」權限，不再參考已移除的「草稿異動」權限。
3. 【調整】前端移除未被任何頁面使用的郵件草稿 API 呼叫與型別定義。

## 注意事項

- 部署順序：先執行 `FirstBank_SQL/2026091701/Deploy_All.sql`（DBA 只需執行這一個檔，可重複執行），再部署後端 API 與前端。
- `Deploy_All.sql` 開頭會先列出目前授權這三個功能的角色清單，供留檔；刪除動作包在同一交易內。
- `Permissions_his`（角色權限異動歷程）不刪除，保留稽核紀錄；曾授權這三個功能的角色，其歷程頁面對應筆數的功能名稱會顯示空白。
- 本次未涉及四種調借方式的簽核流程，調借功能不受影響。
- 後端工作區另有 MonitorData 暫存表相關的未提交異動（`FirstBankContext.cs`、`MonitorDataMapsterConfig.cs` 等），不屬於本次變更。
