# 2026091701 移除信件範本選單下未使用的功能代碼

## 目的

`FeatureDetail` 在信件範本選單（`MenuId = 24`）底下有三筆功能代碼，前後端程式碼皆未使用：

| PK_Id | Feature_Describe | 狀況 |
|---|---|---|
| 4 | 查詢草稿 | 郵件草稿功能未實作，只剩 enum 宣告 |
| 5 | 草稿異動 | 同上；後端僅在 Mail 選單待辦數判斷條件裡順帶列出 |
| 28 | Email 範本設定 | 前後端 enum 皆無此代碼，手動新增的孤兒資料 |

本次連同前後端殘留程式碼一併清除，DB 端移除這三筆及其角色授權。

## 內容

| 檔案 | 說明 |
|---|---|
| `Deploy_All.sql` | **DBA 只需執行這一個檔**。先列出盤點結果，再於同一交易內刪 `Permissions` 授權 → 刪 `FeatureDetail`。可重複執行 |
| `Verify.sql` | 部署後唯讀驗證，每段 Result 應為 OK |

## 注意

- `Permissions_his`（角色權限異動歷程）**不刪**，保留稽核紀錄；該表對 `FeatureDetail` 無 FK，不影響刪除。歷程頁顯示這幾筆舊紀錄時，功能名稱欄會是空白。
- 需搭配同日的後端 API 與前端部署（enum 已移除 4 / 5）。
